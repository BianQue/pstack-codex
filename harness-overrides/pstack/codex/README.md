# pstack for Codex

This downstream package includes the complete published pstack skill suite,
all playbooks, scripts, agent briefs, guides, assets and the dormant Benny pack.
`coverage.json` records every upstream source file and generated skill policy.

Select a skill from this plugin and follow
[the Codex adapter](docs/harness/codex.md). Node.js 24+ and an authenticated Codex CLI
are required. Model and executable settings belong to each local launch spec.

Arena retains independent native CLI candidates, task files and checked
receipts. All other workflows use the same host mappings. External services,
UI control, media rendering and formal toolchains keep their actual prerequisites.
The package does not repair provider encrypted-content handling.

Derived from Lauren Tan's MIT-licensed pstack in cursor/plugins.
See [LICENSE](LICENSE) and the maintenance repository's CODEX.md for releases,
verification, installation and rollback.
